# v2.22.1: App icon for the macOS bundle

To-do only.

## Problem

`install-macos.sh` built the `.app` with only `Contents/MacOS` and `Info.plist`, so Finder and Spotlight showed the generic app icon, and while it ran the Dock showed eframe's default "e" icon, which eframe sets at runtime when the app gives none.

## Changes

- **`todo/app/AppIcon.icns`:** the tray glyph (a rounded check box) in white on the accent tile, generated by `todo/app/icon.py` (Pillow, `iconutil`), with `AppIcon.png` from the same art.
- **App:** sets `AppIcon.png` as its window icon, so the running app's Dock icon matches the bundle.
- **`install-macos.sh`:** copies the icon to `Contents/Resources`, sets `CFBundleIconFile`, and touches the bundle before re-registering it so Finder refreshes the icon.
