# v2.22.1: App icon for the macOS bundle

To-do only.

## Problem

`install-macos.sh` built the `.app` with only `Contents/MacOS` and `Info.plist`, so Finder, the Dock and Spotlight showed the generic app icon.

## Changes

- **`todo/app/AppIcon.icns`:** the tray glyph (a rounded check box) in white on the accent tile, generated by `todo/app/icon.py` (Pillow, `iconutil`).
- **`install-macos.sh`:** copies the icon to `Contents/Resources`, sets `CFBundleIconFile`, and touches the bundle before re-registering it so Finder refreshes the icon.
